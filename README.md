# agent-from-scratch

从零实现一个 Agent，不依赖框架，理解底层原理。

## 目标
- 手写 ReAct 循环
- 工具调用：搜索、计算、读 PDF
- 记忆：对话历史 + 向量数据库
- 规划：任务分解
- 部署：Streamlit + HuggingFace Spaces
